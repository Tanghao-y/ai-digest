Privacy policy

Hermes · last updated 15 November 2026

Data accessed

With the owner's consent, Hermes reads the owner's Gmail through Google's Gmail API with the read-only scope gmail.readonly. It reads messages only when the owner asks it something that needs them.

Where the data goes

The authorization token is stored only on the owner's Mac, readable by the owner's user account alone. Mail is not stored by Hermes beyond answering the question at hand, is not sold, and is not shared with anyone. To answer, Hermes passes the relevant parts of a message to the language model service the owner has chosen for their assistant.

Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions; the token on the Mac then stops working.

Contact

Hermes is a personal project with a single user. Questions can be raised with its owner through GitHub.
